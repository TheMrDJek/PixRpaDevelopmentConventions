## STR-01. Используйте интерполяцию строк вместо конкатенации

**Уровень:** SHOULD — рекомендуется

Интерполяция (`$`) позволяет встраивать выражения C# непосредственно в строку без конкатенации.

```csharp
// Вместо конкатенации:
string message = "Обработано " + fileCount + " файлов в папке " + folderPath;

// Используйте интерполяцию:
string message = $"Обработано {fileCount} файлов в папке {folderPath}";

// Можно использовать выражения и форматирование:
string report = $"Сумма: {amount:C2} | Дата: {date:dd.MM.yyyy}";
```

**Когда использовать в PIX RPA:**
- Формирование сообщений для логирования
- Формирование текстов писем и уведомлений
- Формирование имен файлов (для путей используйте `Path.Combine`, см. [FS-02](files.md#fs-02-не-используйте-жестко-заданные-пути-и-конкатенацию-строк-для-путей))

```csharp
string logMessage = $"[{transactionId}] Обработка файла {fileName}";
string reportFileName = $"{reportName}_{DateTime.Now:yyyy-MM-dd}.xlsx";
```

> [!CAUTION]
> Никогда не подставляйте значения в SQL-запрос через интерполяцию или конкатенацию строк. Это открывает возможность SQL-инъекции и ломает запрос, если в данных встретится кавычка. Передавайте значения через параметры запроса (см. [DB-05](../01-conventions/database.md#db-05-передавайте-значения-в-запросы-только-через-параметры)).

## STR-02. Используйте string.Format для шаблонов из конфигурации

**Уровень:** SHOULD — рекомендуется

Интерполяция работает только со строкой, которая написана в коде. Если шаблон сообщения хранится вне кода — в ассете, в файле шаблона, в настройках рассылки, — используйте `string.Format` с позиционными заполнителями `{0}`, `{1}`.

```csharp
// Ассет Param_AP_Email_SubjectTemplate: "Счет {0} от {1:dd.MM.yyyy} обработан"
string subjectTemplate = assets["Param_AP_Email_SubjectTemplate"];
string subject = string.Format(subjectTemplate, invoiceNumber, invoiceDate);
// "Счет INV-123 от 15.06.2025 обработан"
```

**Правила:**
- Для строк, написанных в коде, предпочитайте интерполяцию: ее легче читать, и в ней нельзя перепутать порядок аргументов
- Документируйте в описании ассета, какие аргументы и в каком порядке подставляются
- Количество заполнителей в шаблоне должно совпадать с количеством аргументов: лишний заполнитель `{2}` приводит к `FormatException` во время работы робота
- Фигурные скобки в тексте шаблона экранируются удвоением: `{{` и `}}`
- Для форматирования чисел и дат, которые увидит пользователь, указывайте культуру явно: `string.Format(new CultureInfo("ru-RU"), template, amount)`

## STR-03. Используйте дословные строки для путей и многострочного текста

**Уровень:** SHOULD — рекомендуется

Дословные строки (`@`) позволяют не экранировать обратные слеши и записывать многострочный текст.

```csharp
// Вместо экранирования обратных слешей:
string pattern = "\\d{3}\\\\\\d{2}";

// Используйте дословные строки:
string pattern = @"\d{3}\\\d{2}";

// Многострочный текст: текст запроса — дословная строка, значения — параметры
string query = @"
SELECT OrderId, Amount
FROM Orders
WHERE CustomerID = @customerId
  AND OrderDate >= @startDate";
```

**Когда использовать в PIX RPA:**
- SQL-запросы
- Регулярные выражения
- XML/HTML-шаблоны
- Пути к файлам, если путь действительно нужно записать в коде (обычно пути берутся из ассетов, см. [HC-01](hardcoding.md#hc-01-не-используйте-жесткое-кодирование))

Дословные строки можно комбинировать с интерполяцией:

```csharp
string logEntry = $@"Время: {DateTime.Now:HH:mm:ss}
Пользователь: {userName}";
```

## STR-04. Используйте необработанные строковые литералы для JSON и XML

**Уровень:** MAY — допустимо

Необработанные строковые литералы (`"""`) позволяют работать с многострочным текстом, сохраняя форматирование и не экранируя кавычки.

```csharp
string json = """
{
    "name": "PIX Robot",
    "version": "1.0",
    "settings": {
        "timeout": 30,
        "retryCount": 3
    }
}
""";
```

> [!NOTE]
> Доступны в версиях PIX RPA, которые работают на .NET 8 и выше.

## STR-05. Используйте StringBuilder для сборки строки в цикле

**Уровень:** SHOULD — рекомендуется

Строки в C# неизменяемы: каждая конкатенация в цикле создает новую строку. Для сборки текста из большого числа частей (отчет, тело письма со списком строк, CSV) используйте `StringBuilder`.

```csharp
var report = new StringBuilder();
report.AppendLine("Номер;Сумма;Статус");

foreach (DataRow row in resultTable.Rows)
{
    report.AppendLine($"{row["Number"]};{row["Amount"]};{row["Status"]}");
}

File.WriteAllText(reportPath, report.ToString());
```

Для объединения коллекции через разделитель достаточно `string.Join(";", values)`.

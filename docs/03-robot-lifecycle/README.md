# Жизненный цикл робота

Робот — это не только код. Большая часть проблем в RPA возникает не при написании скриптов, а на границах этапов: процесс автоматизировали, не оценив его стабильность; робот ушел в прод без понятного плана поддержки; изменение в целевой системе обнаружили по жалобе бизнеса. Этот раздел описывает этапы, через которые проходит каждый робот, и что должно быть готово на выходе каждого этапа.

## Этапы

```mermaid
flowchart LR
    A[Оценка процесса] --> B[Проектирование]
    B --> C[Разработка]
    C --> D[Тестирование]
    D --> E[Релиз]
    E --> F[Hypercare]
    F --> G[Эксплуатация]
    G -->|изменения| B
    G --> H[Вывод из эксплуатации]
```

| Этап | Результат этапа | Раздел |
|------|-----------------|--------|
| Оценка процесса | Решение «автоматизируем / не автоматизируем», оценка эффекта | [Оценка процесса](assessment.md) |
| Проектирование | Согласованные PDD и SDD | [Проектирование](design.md) |
| Разработка | Код в репозитории, прошедший ревью | [Соглашения](../01-conventions/), [Рекомендации](../02-guidelines/), [Код-ревью](code-review.md) |
| Тестирование | Пройденные тесты, подписанный акт UAT | [Тестирование](testing.md) |
| Релиз | Версия робота на контуре PROD | [Релиз и развертывание](release-and-deploy.md) |
| Hypercare и эксплуатация | Runbook, мониторинг, передача в поддержку | [Сопровождение](support.md) |
| Документирование | Документация робота | [Документирование роботов](documentation.md) |

## Роли

| Роль | Зона ответственности |
|------|----------------------|
| Владелец процесса (бизнес) | Описание процесса, приемка, решение по бизнес-исключениям |
| Бизнес-аналитик | Оценка процесса, PDD, тестовые сценарии |
| Разработчик RPA | SDD, разработка, модульные и интеграционные тесты |
| Техлид / архитектор | Ревью SDD и кода, соблюдение соглашений |
| Администратор PIX Master | Контуры, ассеты, расписания, учетные записи роботов |
| Поддержка | Мониторинг, разбор инцидентов по runbook |

В небольшой команде одна и та же персона может совмещать несколько ролей, но результат каждого этапа все равно должен существовать.

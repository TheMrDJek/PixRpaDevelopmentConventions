## Безопасность и данные

- [ ] В коде, файлах проекта и истории коммитов нет паролей, токенов, строк подключения с паролем: [CONFIG-05](1-project/config.md#config-05-храните-секреты-в-защищенных-ассетах)
- [ ] В логах, статусах очереди, текстах исключений и именах файлов нет персональных и конфиденциальных данных: [PRIVACY-02](2-develop/privacy.md#privacy-02-не-допускайте-персональные-данные-в-логи-статусы-и-имена-файлов), [LOG-02](2-develop/log.md#log-02-не-логируйте-конфиденциальные-данные)
- [ ] SQL-запросы параметризованы: [DB-02](3-integrations/db.md#db-02-передавайте-значения-в-запросы-только-через-параметры)
- [ ] Передача данных во внешние сервисы и LLM согласована: [PRIVACY-05](2-develop/privacy.md#privacy-05-не-передавайте-персональные-данные-во-внешние-сервисы-без-согласования), [AI-01](2-develop/ai.md#ai-01-не-передавайте-конфиденциальные-данные-во-внешние-модели-без-согласования)

## Надежность

- [ ] Бизнес- и технические исключения разделены: [ERROR-03](2-develop/error.md#error-03-разделяйте-бизнес-исключения-и-технические-исключения)
- [ ] Нет пустых `catch` и try/catch для управления потоком: [ERROR-02](2-develop/error.md#error-02-не-оставляйте-catch-пустым-и-не-используйте-trycatchfinally-в-бизнес-логике)
- [ ] Исключения содержат источник: [ERROR-04](2-develop/error.md#error-04-указывайте-источник-исключения)
- [ ] Повторная обработка транзакции не создает дубликатов: [RECOVERY-01](2-develop/recovery.md#recovery-01-делайте-обработку-транзакции-идемпотентной)
- [ ] Статус элемента очереди обновляется последним: [QUEUE-01](3-integrations/queue.md#queue-01-обрабатывайте-элемент-очереди-как-транзакцию)
- [ ] Поставщик задает элементу уникальную ссылку: [QUEUE-06](3-integrations/queue.md#queue-06-задавайте-элементу-очереди-уникальную-ссылку)
- [ ] В очереди задан таймаут для статуса Processing, робот подтверждает элемент при любом исходе: [QUEUE-07](3-integrations/queue.md#queue-07-ограничивайте-время-элемента-в-статусах-new-и-processing)
- [ ] Робот останавливается после серии технических ошибок и проверяет сигнал остановки: [RECOVERY-02](2-develop/recovery.md#recovery-02-останавливайте-робота-после-серии-технических-исключений-подряд), [RECOVERY-03](2-develop/recovery.md#recovery-03-проверяйте-сигнал-остановки-от-мастера)
- [ ] У каждого цикла ожидания и внешнего вызова есть таймаут: [LOOP-01](2-develop/loop.md#loop-01-ограничивайте-каждый-цикл-таймаутом-или-числом-итераций), [INTEGRATION-01](3-integrations/integration.md#integration-01-задавайте-таймауты-для-всех-внешних-вызовов)
- [ ] Нет Excel Interop и Outlook COM: [EXCEL-01](3-integrations/excel.md#excel-01-не-используйте-excel-interop-и-com), [MAIL-01](3-integrations/mail.md#mail-01-работайте-с-почтой-по-протоколам-а-не-через-outlook)
- [ ] Временные файлы удаляются: [FILE-02](2-develop/file.md#file-02-управляйте-временными-файлами)

## Конфигурация и структура

- [ ] Нет жестко закодированных путей, адресов, порогов, получателей: [CONFIG-01](1-project/config.md#config-01-не-зашивайте-настройки-в-код), [FILE-01](2-develop/file.md#file-01-не-используйте-жестко-заданные-пути-и-конкатенацию-строк-для-путей)
- [ ] Во входных параметрах только значения запуска: [CONFIG-06](1-project/config.md#config-06-используйте-входные-параметры-робота-только-для-значений-запуска)
- [ ] Логика размещена в правильных слоях и состояниях: [TEMPLATE-01](1-project/template.md#template-01-раскладывайте-скрипты-по-папкам-по-роли), [TEMPLATE-02](1-project/template.md#template-02-выполняйте-в-каждом-состоянии-только-его-работу)
- [ ] Уровни логирования соответствуют соглашению, в записях есть ID транзакции: [LOG-01](2-develop/log.md#log-01-используйте-подходящие-уровни-логирования), [LOG-03](2-develop/log.md#log-03-указывайте-идентификатор-транзакции-в-каждой-записи-лога)

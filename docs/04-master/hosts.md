# Хосты

Хосты в PIX Master — это серверы или рабочие станции, на которых выполняются роботы. Правильная настройка и именование хостов упрощает управление инфраструктурой.

## HST-01. Именуйте хосты по формату {Контур}-{Расположение}-{Назначение}-{Номер}

**Уровень:** MUST — обязательно

- Используйте формат: `{Контур}-{Расположение}-{Назначение}-{Номер}`
- Примеры:
  - `PROD-MSK-AP-01` — продуктивный сервер в Москве для Accounts Payable, первый экземпляр
  - `DEV-SPB-FIN-03` — сервер разработки в Санкт-Петербурге для процессов Finance, третий экземпляр
  - `UAT-MSK-HR-02` — тестовая машина в Москве для процессов HR, второй экземпляр

**Контуры** (совпадают с контурами ассетов, см. [CFG-01](../01-conventions/config-and-secrets.md#cfg-01-используйте-ассеты-мастера-для-хранения-конфигурации)):
- `PROD` — продуктивная среда
- `UAT` — среда тестирования и приемки
- `DEV` — среда разработки
- `TRAIN` — учебная среда

## HST-02. Группируйте хосты по назначению

**Уровень:** SHOULD — рекомендуется

- Создавайте логические группы хостов по назначению или проекту
- Используйте теги для дополнительной категоризации хостов
- Примеры групп: `Finance`, `HR`, `Sales`, `Shared`

## HST-03. Стандартизируйте конфигурацию хостов

**Уровень:** MUST — обязательно

- Документируйте минимальные системные требования для каждого типа хоста
- Стандартизируйте настройки безопасности и доступа
- Настраивайте автоматическое резервное копирование конфигураций
- Обеспечьте регулярное обновление хостов для безопасности

**Требования к окружению для UI-автоматизации.** Роботы, работающие с интерфейсом, чувствительны к окружению. Одинаково настройте на всех хостах одного назначения и зафиксируйте в документации:
- разрешение экрана и масштаб (DPI)
- региональные настройки: язык интерфейса, формат дат и чисел, раскладку клавиатуры по умолчанию
- версии целевых приложений и браузеров, настройки автообновления
- поведение сессии: отключение блокировки экрана и заставки, работа в отключенной RDP-сессии

Расхождение этих настроек между UAT и PROD — частая причина ситуации «на тесте работало, в проде падает».

# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/): MAJOR — изменение структуры или смысла правил, MINOR — новые правила, PATCH — уточнения и исправления.

## [2.0.0] - 2026-09-24

### Изменено
- README разбит на отдельные файлы в `docs/`: соглашения, рекомендации, жизненный цикл робота, PIX Master
- Каждому правилу присвоены идентификатор и уровень обязательности MUST / SHOULD / MAY
- Блоки `<details>` заменены на заголовки, в каждый файл добавлено содержание
- Объединены дублирующиеся разделы: условия, работа с файлами, очереди
- Крупные рекомендации разбиты на отдельные правила: строки, LINQ, UI, принципы проектирования
- Правило об общих библиотеках заменено правилом о версионированных библиотеках (PRJ-05)
- Примечания оформлены как GitHub alerts (#34)
- Картинки перенесены из `common/` в `images/<раздел>/`

### Добавлено
- Соглашение об администрировании PIX Master: очереди, хосты, агенты, задачи, ассеты, мониторинг (#28)
- Жизненный цикл робота: оценка процесса, проектирование (PDD/SDD), тестирование (#6), код-ревью, релиз, сопровождение
- Надежность: идемпотентность, восстановление, остановка после серии ошибок (REL)
- Персональные данные и 152-ФЗ (PD)
- Интеграции: выбор канала, таймауты, учетные записи, HttpClient (#11)
- Работа с Excel без Interop (XLS), работа с почтой по SMTP/IMAP/Exchange (MAIL)
- ИИ и интеллектуальная обработка документов (AI)
- Бизнес- и системные исключения (EXC-06), источник исключения (EXC-07, #43)
- Параметризованные SQL-запросы (DB-05), ID транзакции в логах (LOG-07)
- Входные параметры робота (CFG-03, #25)
- string.Format (STR-02, #42), StringBuilder (STR-05)
- «Цикл с … по» для ожидания UI (LOOP-03, #40), «Цикл для каждого» (LOOP-04, #27)
- File/Directory и FileInfo/DirectoryInfo, оператор `|=` (FS-05, #33, #35)
- Типы процессов, недостатки State Machine (#37, #38), Dispatcher/Performer и доменный формат (PRJ-06, #39), Transaction Script (PRJ-07, #2), заготовка для других шаблонов (#18)
- Инициализация коллекций в столбик (CS-09, #12)
- Реестр правил, глоссарий, шаблоны PDD, SDD, runbook, чек-лист код-ревью, `.gitignore` для робота
- CONTRIBUTING, шаблоны Issue и Pull Request, проверка содержания и ссылок в CI

### Исправлено
- Пример SQL-запроса через интерполяцию строк заменен на параметризованный запрос
- Пустой `catch` в примерах работы с файлами и UI
- Пример выхода из вложенных циклов через исключение
- Форматирование примера LINQ-запроса

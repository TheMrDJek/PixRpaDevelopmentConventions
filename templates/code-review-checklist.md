# Чек-лист код-ревью

Используется по правилу [REV-01](../docs/03-robot-lifecycle/code-review.md#rev-01-проверяйте-изменения-по-чек-листу). Порядок пунктов — от самых дорогих для исправления после релиза к самым дешевым. Полный список правил — в [реестре](../docs/rules-index.md).

## Безопасность и данные

- [ ] В коде, файлах проекта и истории коммитов нет паролей, токенов, строк подключения с паролем — [GIT-05](../docs/01-conventions/git.md#git-05-не-коммитьте-конфиденциальные-данные), [CFG-02](../docs/01-conventions/config-and-secrets.md#cfg-02-используйте-зашифрованные-ассеты-для-хранения-конфиденциальных-данных)
- [ ] В логах, статусах очереди, текстах исключений и именах файлов нет персональных и конфиденциальных данных — [PD-02](../docs/01-conventions/personal-data.md#pd-02-не-допускайте-персональные-данные-в-логи-статусы-и-имена-файлов), [LOG-06](../docs/01-conventions/logging.md#log-06-не-логируйте-конфиденциальные-данные)
- [ ] SQL-запросы параметризованы — [DB-05](../docs/01-conventions/database.md#db-05-передавайте-значения-в-запросы-только-через-параметры)
- [ ] Передача данных во внешние сервисы и LLM согласована — [PD-05](../docs/01-conventions/personal-data.md#pd-05-не-передавайте-персональные-данные-во-внешние-сервисы-без-согласования), [AI-01](../docs/02-guidelines/ai-and-idp.md#ai-01-не-передавайте-конфиденциальные-данные-во-внешние-модели-без-согласования)

## Надежность

- [ ] Бизнес- и системные исключения разделены — [EXC-06](../docs/01-conventions/exceptions.md#exc-06-разделяйте-бизнес-исключения-и-системные-исключения)
- [ ] Нет пустых `catch` и try/catch для управления потоком — [EXC-03](../docs/01-conventions/exceptions.md#exc-03-не-оставляйте-catch-пустым-и-не-используйте-trycatchfinally-в-бизнес-логике)
- [ ] Исключения содержат источник — [EXC-07](../docs/01-conventions/exceptions.md#exc-07-указывайте-источник-исключения)
- [ ] Повторная обработка транзакции не создает дубликатов — [REL-01](../docs/01-conventions/reliability.md#rel-01-делайте-обработку-транзакции-идемпотентной)
- [ ] Статус элемента очереди обновляется последним — [QUE-02](../docs/01-conventions/queues.md#que-02-обрабатывайте-элемент-очереди-как-транзакцию)
- [ ] Робот останавливается после серии системных ошибок и проверяет сигнал остановки — [REL-05](../docs/01-conventions/reliability.md#rel-05-останавливайте-робота-после-серии-системных-исключений-подряд), [REL-06](../docs/01-conventions/reliability.md#rel-06-проверяйте-сигнал-остановки-от-мастера)
- [ ] У каждого цикла ожидания и внешнего вызова есть таймаут — [LOOP-02](../docs/02-guidelines/loops-and-goto.md#loop-02-ограничивайте-каждый-цикл-таймаутом-или-числом-итераций), [INT-02](../docs/02-guidelines/integrations.md#int-02-задавайте-таймауты-для-всех-внешних-вызовов)
- [ ] Нет Excel Interop и Outlook COM — [XLS-01](../docs/02-guidelines/excel.md#xls-01-не-используйте-excel-interop-и-com), [MAIL-01](../docs/02-guidelines/email.md#mail-01-работайте-с-почтой-по-протоколам-а-не-через-outlook)
- [ ] Временные файлы удаляются — [FS-03](../docs/02-guidelines/files.md#fs-03-управляйте-временными-файлами)

## Конфигурация и структура

- [ ] Нет жестко закодированных путей, адресов, порогов, получателей — [HC-01](../docs/02-guidelines/hardcoding.md#hc-01-не-используйте-жесткое-кодирование), [FS-02](../docs/02-guidelines/files.md#fs-02-не-используйте-жестко-заданные-пути-и-конкатенацию-строк-для-путей)
- [ ] Во входных параметрах только значения запуска — [CFG-03](../docs/01-conventions/config-and-secrets.md#cfg-03-используйте-входные-параметры-робота-только-для-значений-запуска)
- [ ] Логика размещена в правильных слоях и состояниях — [PRJ-01](../docs/01-conventions/project-structure.md#prj-01-разделяйте-проект-на-слои), [PRJ-03](../docs/01-conventions/project-structure.md#prj-03-используйте-состояния-по-назначению)
- [ ] Уровни логирования соответствуют соглашению, в записях есть ID транзакции — [LOG-03](../docs/01-conventions/logging.md#log-03-используйте-подходящие-уровни-логирования), [LOG-07](../docs/01-conventions/logging.md#log-07-указывайте-идентификатор-транзакции-в-каждой-записи-лога)

## Читаемость

- [ ] Имена соответствуют соглашению — [Именование](../docs/01-conventions/naming.md)
- [ ] Нет больших блоков кода в активности «Выполнить» — [ACT-01](../docs/02-guidelines/pix-activities.md#act-01-не-размещайте-большой-код-в-активности-выполнить)
- [ ] Вложенность условий не больше 2–3 уровней — [CND-02](../docs/02-guidelines/conditions.md#cnd-02-избегайте-глубоких-вложений-в-скриптах)
